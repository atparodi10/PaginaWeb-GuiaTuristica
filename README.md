# Web Turística: Descubre Tokio

## Descripción
Esta es una página web interactiva y moderna que presenta información turística sobre **Tokio**, la vibrante capital de Japón. La web está diseñada para ofrecer a los visitantes un recorrido visual y atractivo, destacando la historia, lugares emblemáticos, galerías de imágenes y un mapa interactivo de la ciudad.

El objetivo principal de la web es proporcionar una **experiencia inmersiva** a través de un diseño moderno inspirado en colores y luces de ciudad futurista, combinado con animaciones suaves y efectos visuales llamativos.

## Estructura de la Web
La página cuenta con las siguientes secciones:

- **Inicio:** Sección principal con imagen panorámica de Tokio y una breve introducción.
- **Historia:** Espacio dedicado a la historia de Tokio (contenido pendiente o de relleno para personalizar).
- **Galería:** Muestra de imágenes representativas de la ciudad.
- **Lugares turísticos:** Sección para listar sitios importantes para visitar.
- **Mapa:** Ubicación geográfica de Tokio mediante un iframe interactivo (Google Maps/OpenStreetMap).

## Tecnologías Utilizadas
- **HTML5:** Estructura de la página.
- **CSS3:** Estilo visual, colores, tipografía, diseño responsivo y animaciones.
- **JavaScript:** Animaciones de entrada, efectos de desplazamiento suave y mejoras interactivas.
- **Fuentes Web:** Tipografía moderna como `Poppins` o `Roboto`.
- **Imágenes:** Recursos desde URLs públicas (por ejemplo Unsplash) para ilustrar la ciudad.

## Características
- Diseño moderno y responsivo, adaptado a móviles y escritorio.
- Navbar con efecto de degradado y hover en los enlaces.
- Animaciones suaves para títulos y textos principales.
- Integración de mapa interactivo mostrando la ubicación exacta de Tokio.
- Comentarios claros en el código para facilitar la edición y personalización.

## Cómo usar
1. Descargar o clonar el repositorio.
2. Abrir el archivo `index.html` en cualquier navegador moderno.
3. Navegar por las secciones usando el navbar.
4. Personalizar los contenidos, imágenes y textos según sea necesario.
